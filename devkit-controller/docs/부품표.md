# SilverTalk DevKit 부품표

제작자 SunjooAn · Android 앱 1.10 · ESP32 DevKit 펌웨어 1.8

|수량|부품|사양·예시|
|---:|---|---|
|1|ESP32 DevKit|USB-C ESP32-WROOM-32, 4MB, CH340 USB 시리얼. 이 앱은 USB VID/PID 1A86:7523을 인식|
|1|OLED|SSD1306 I²C 128×64, 4핀, 주소 0x3C, 3.3V 사용|
|1|유지형 선택 스위치|2단 SPST ON/OFF. SPDT ON/ON을 쓰면 공통과 한쪽 접점만 사용|
|2|순간식 버튼|패널 장착형 NO 타입. 대화 시작·종료 및 PTT|
|4|5mm LED|마이크 적색, 대화 황색, A 녹색, B 청색 예시. 낮은 순방향 전압의 고효율 타입 권장|
|4|저항|220Ω 1/4W. GPIO19·26·27·32에서 각 LED 양극까지 하나씩 직렬 연결|
|1 (선택)|연속 대화 버튼|패널 장착형 순간식 NO 타입. GPIO33과 GND 사이에 연결|
|1 (선택)|연속 대화 5mm LED|GPIO13에서 220Ω 1/4W 저항을 거쳐 LED 양극에 연결하고 음극을 GND에 연결|
|1|USB-C PD 허브|PD 입력과 USB 2.0 이상 데이터 포트. 해당 갤럭시에서 호스트 통신과 충전 동시 지원 확인|
|1|USB-C PD 충전기|허브의 PD 입력 조건을 충족하는 제품|
|1|USB 데이터 케이블|허브 데이터 포트에서 DevKit USB-C까지 연결|
|1|갤럭시 및 거치대|Android 앱, 마이크와 스피커에 사용|
|필요량|점퍼선과 케이스|신호선과 공통 GND 연결|

Wi-Fi로 독립 구동할 때 DevKit은 별도 USB 5V 전원에 연결할 수 있습니다. 갤럭시는 별도로 충전합니다.
