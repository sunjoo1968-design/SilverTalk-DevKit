# ESP32 DevKit 펌웨어 플래싱

제작자 SunjooAn · ESP32 DevKit 펌웨어 1.8 · 갤럭시 앱 1.9

대상은 USB-C와 CH340이 달린 **ESP32-WROOM-32 DevKit, 플래시 4MB**입니다. 배포 ZIP을 Windows PC에 풀고, 아래 명령은 PowerShell에서 실행합니다.

## 1. PC에서 보드 확인

1. 데이터 통신이 되는 USB 케이블로 DevKit을 PC에 직접 연결합니다. 시리얼 모니터와 COM 포트를 잡고 있는 다른 프로그램을 닫습니다.
2. 다음 명령으로 esptool 4.13.0을 설치하고 포트 목록을 확인합니다.

   ```powershell
   py -m pip install "esptool==4.13.0"
   py -m serial.tools.list_ports -v
   ```

3. 목록에서 **USB-SERIAL CH340**을 찾습니다. 보드를 뺐다가 꽂을 때 사라지고 나타나는 COM 번호인지 확인합니다. 아래 예시는 COM20이며, PC에 표시되는 번호로 바꿉니다.

   ```powershell
   $port = 'COM20'
   py -m esptool --chip esp32 --port $port --baud 115200 flash_id
   ```

   출력에서 ESP32 칩과 `Detected flash size: 4MB`를 확인합니다. 다른 칩이나 용량이 나오면 해당 보드용 파일을 확인한 뒤 진행합니다.

## 2. 설치할 파일 고르기

| 상황 | 펌웨어 파일 | 기록 주소 |
| --- | --- | --- |
| 기존 SilverTalk DevKit 업데이트. Wi-Fi 설정 유지 | `SilverTalk-DevKit-1.8-update.bin` | `0x10000` |
| 새 DevKit 또는 전체를 SilverTalk로 바꿀 보드 | `SilverTalk-DevKit-1.8.bin` | `0x0` |
| 펌웨어 1.8이 설치되어 있고 갤럭시 앱만 업데이트 | `SilverTalk-DevKit-1.9.apk`를 갤럭시에 설치 | 펌웨어 기록 생략 |

## 3. 기존 보드 백업 및 앱 영역 업데이트

압축을 푼 폴더에서 실행하세요. 아래 백업에는 이전 펌웨어와 보드에 저장된 Wi-Fi 정보가 포함될 수 있으므로 개인 PC에 보관하세요.

```powershell
py -m esptool --chip esp32 --port $port --baud 460800 read_flash 0x0 0x400000 .\esp32-before-update.bin
py -m esptool --chip esp32 --port $port --baud 460800 write_flash 0x10000 .\SilverTalk-DevKit-1.8-update.bin
py -m esptool --chip esp32 --port $port --baud 460800 verify_flash 0x10000 .\SilverTalk-DevKit-1.8-update.bin
```

`write_flash`에서 `Hash of data verified`가 나오면 기록 데이터가 확인된 것입니다. 기존 설정을 보존하려면 이 절차에서 `erase_flash`와 `--erase-all`을 사용하지 마세요. 업데이트 파일의 기록 범위는 앱 영역부터 시작하며 Wi-Fi 설정은 앞쪽 NVS 영역에 저장됩니다.

설정 영역을 바이트 단위로 확인하려면 업데이트 직전과 직후에 다음 두 명령을 각각 실행하고 해시를 비교할 수 있습니다.

```powershell
py -m esptool --chip esp32 --port $port --baud 115200 read_flash 0x9000 0x6000 .\nvs-before.bin
# 앱 영역 업데이트를 마친 뒤 실행
py -m esptool --chip esp32 --port $port --baud 115200 read_flash 0x9000 0x6000 .\nvs-after.bin
Get-FileHash -LiteralPath .\nvs-before.bin,.\nvs-after.bin
```

## 4. 새 보드에 초기 설치

새 보드에는 부트로더, 파티션 테이블, 앱이 포함된 통합 파일을 기록합니다. 기존에 다른 펌웨어가 있으면 3절의 전체 백업부터 실행하세요.

```powershell
py -m esptool --chip esp32 --port $port --baud 460800 write_flash --flash_mode dio --flash_freq 40m --flash_size 4MB 0x0 .\SilverTalk-DevKit-1.8.bin
```

기록이 끝나면 필요할 때 `EN`을 한 번 눌러 정상 부팅합니다. OLED에서 `SUNJOOAN V1.8`과 연결 상태를 확인합니다. 새 보드의 Wi-Fi는 [설치 안내](설치안내.md)에 따라 갤럭시에서 등록하세요.

## 5. 연결이 안 될 때

- **COM 포트가 보이지 않음**. 데이터용 USB 케이블과 다른 PC USB 포트를 사용하고, 장치 관리자에서 CH340 포트를 확인하세요.
- **포트 액세스 오류**. 시리얼 모니터나 이전 플래싱 프로그램을 닫고 보드를 연결한 뒤 COM 번호를 다시 확인하세요.
- **`Connecting...`에서 멈춤**. 보드의 `BOOT`를 누른 채 `EN`을 눌렀다가 떼고, `BOOT`를 누른 채 명령을 실행하세요. `Chip is ESP32`가 나오면 `BOOT`를 뗍니다.
- **기록 중 통신 오류**. `--baud 460800`을 `--baud 115200`으로 낮춰 같은 파일과 주소로 다시 시도하세요.
- **기록 후 OLED 화면이 비어 있음**. `EN`을 누르고 SSD1306의 전원과 SDA GPIO21, SCL GPIO22, I²C 주소 `0x3C`를 확인하세요.
