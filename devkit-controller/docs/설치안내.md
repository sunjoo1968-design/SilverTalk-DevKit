# SilverTalk DevKit 설치 안내

제작자 SunjooAn · Android 앱 1.9 · ESP32 DevKit 펌웨어 1.8

## 설치

1. 갤럭시에 `SilverTalk-DevKit-1.9.apk`를 설치합니다. 기존 SilverTalk DevKit 위에 업데이트하면 저장된 보호자 설정과 박스 등록 정보를 이어서 사용합니다.
2. 기존 SilverTalk ESP32-WROOM-32 DevKit은 `SilverTalk-DevKit-1.8-update.bin`을 `0x10000`에 기록합니다. 전체 플래시 초기화를 실행하지 않아야 기존 Wi-Fi 설정이 유지됩니다. 새 4MB DevKit에는 통합 파일 `SilverTalk-DevKit-1.8.bin`을 `0x0`에 기록합니다. 박스에 이미 펌웨어 1.8이 설치돼 있으면 앱만 업데이트하세요.
3. [배선도](배선도.svg)와 [부품표](부품표.md)에 따라 박스를 연결합니다. 충전과 유선 연결은 갤럭시가 USB 호스트와 충전을 동시에 지원하는 USB-C PD 허브 조합에서 확인하세요.

[펌웨어 플래싱 상세 안내](펌웨어-플래싱.md)에서 COM 포트 확인, 백업, 기록 명령, 오류 대응을 확인할 수 있습니다.

## 보호자 초기 설정

1. SilverTalk 앱의 연결 안내에 따라 USB 연결을 허용하고 **SilverTalk 박스 연결** 접근성 서비스를 켭니다.
2. 사용할 AI 앱을 설치하고 로그인과 마이크 권한 설정을 마칩니다. SilverTalk의 **보호자 설정 → A·B 서비스 배정**에서 ChatGPT, Gemini Live, Sesame, Pi 중 원하는 서비스를 선택합니다. 기본값은 A Sesame, B Gemini Live입니다.
3. Wi-Fi를 쓰려면 USB 연결 상태에서 **갤럭시의 현재 Wi-Fi 사용**을 선택하고 비밀번호를 입력해 박스로 전송합니다. 등록 후에는 박스를 별도 USB 전원으로 켜고 같은 네트워크에서 자동 연결을 확인합니다.
4. 연결 유지와 일정 읽기는 보호자 설정에서 조정합니다.

## 버튼과 LED 확인

- 서비스 선택 스위치를 바꾸면 OLED와 A·B LED에 선택 결과가 표시됩니다.
- 대기 버튼을 처음 짧게 누르면 화면이 깨어나고 선택한 앱이 열립니다. 준비 상태에서 한 번 더 누르면 통화가 연결되고 음소거 대기로 들어갑니다.
- 말하기 버튼을 누르는 동안 마이크 LED가 점멸합니다. 버튼을 떼면 음소거 대기로 돌아갑니다.
- 통화 중 대기 버튼을 3초 누르면 연속 대화가 시작되고, 짧게 누르면 음소거로 돌아갑니다. GPIO33 전용 버튼을 추가한 경우 짧게 눌러 연속 대화를 켜고 끌 수 있습니다. GPIO13 전용 LED는 연속 대화 중 마이크가 열렸을 때 계속 켜집니다.
- 연속 대화를 켜고 15초 이상 말하지 않은 뒤 마이크가 계속 열려 있는지, 짧게 누르면 닫히는지 확인합니다.

Galaxy A20에서 Gemini Live 연속 대화와 Wi-Fi 지연 대응을 확인했습니다. 다른 기종의 PD 충전·유선 동시 동작, 각 서비스 앱 버전의 제어 동작, 전용 버튼과 LED의 실물 동작은 설치 환경에서 확인하세요.

음성 제어 흐름은 Sesami · ChatGPT Pro Micro V1 샘플을 참고했습니다. USB 시리얼 라이선스는 배포 파일에 포함돼 있습니다.
